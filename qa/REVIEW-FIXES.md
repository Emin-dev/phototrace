# Review fixes, 2026-10-09

These changes address reproduced correctness, recovery, packaging, and accessibility-source issues. Real browser, pixels, assistive-technology, and deployment verification remain pending.

## Domain logic

1. Mixed hash/path lookup double-claimed a destination. The engine now counts every source candidate claim before resolving any pair; any shared destination is ambiguous for all competing sources. Regression fixture `tests/fixtures/phototrace-double-claim.json`, native test and actual-WASM test both pass.
2. Edited→edited cyclic links were shown as covered. Coverage now requires both referenced IDs to exist, be original root records without their own parent, and be uniquely reconciled. Cycles/chains produce `invalid original reference`; omitted originals remain unreconciled/unknown. Original records with a parent are invalid relationships. Cyclic fixture, native/WASM regression and positive valid-original/edit test pass.

## Transactional state and resource/error handling

3. Invalid replacement manifests/files used to destroy notes and the prior report. Validation now precedes committing the replacement. Count, byte-size, syntax, complete record schema, strings, hashes, paths, metadata and file-name validation happen while the prior state remains intact. Invalid file selection also preserves prior data. Exact-source control-flow regression tests cover oversized, malformed, semantic and nested inputs.
4. A deeply nested unknown property reached structured clone and left controls/worker live. `validation.js` rejects unknown properties and nonprimitive leaves without recursion before dispatch. Worker construction and postMessage are inside guaranteed error-cleanup paths; both injected failures preserve previous results and restore retry controls. The 10,000-level supplied repro is rejected without starting a Worker.
5. Superseded sample fetch success/failure and stale same-side import completion are guarded using operation tickets. A newer Compare also supersedes pending input fetches. Source control-flow regressions cover the reported stale fetch failure and success.

## Accessibility source corrections

6. Selecting a row updates its state without replacing the row node, then focuses the inspector consistently on desktop/mobile. Back to file list returns to the selected row (or search if filtered out). Reduced-motion users receive instant scroll.
7. Source/destination Import manifest and Hash local files actions have distinct accessible names.
8. The existing live status channel announces completion counts. Filtered record count is also live. Download feedback accurately says “requested.”

DOM/Worker-shim tests establish source control flow and node identity only, not real accessibility-tree/focus/AT behavior. The browser suite is updated to verify these changes when a reachable preview is reachable.

## Safe replacement confirmation

Validated manifest/file replacements and Load sample now stage new inputs while retaining the current report, notes, acknowledgements, and exportability. If meaningful human review exists, a native labelled dialog defaults focus to Keep current review, offers Export audit first without closing or committing, and requires the explicit Replace and clear review action. Escape keeps the session. Invalid inputs never trigger the warning; initial sample startup with no human review has no warning.

The confirmation checks operation tickets again after awaiting, preventing a superseded selection from committing. Twenty exact-source control-flow tests include invalid input, keep/confirm for manifest/files/sample, export-before-invalidation, empty startup, newer compare cancellation, and stale-after-confirm races. The browser runner includes corresponding native dialog, download, Escape, and keep/confirm checks, but actual browser/AT execution remains pending.

## Primary-action contrast

Shared enabled primary buttons, including the replacement confirmation, now use white on #b55330 (4.947:1) and white on #984124 on hover (6.738:1). Focus and active states retain the compliant normal colors unless hovered. Four source-color regression checks enforce at least 4.5:1; actual pixel/AT testing and comprehensive conformance remain pending. Disabled buttons are not an enabled action state and remain visually disabled.
