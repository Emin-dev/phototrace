    HONEST BY DESIGN
    A check, with clear boundaries.
    Phototrace compares the inventories you supply. It never scans your whole device or establishes a complete iPhone Photos inventory.
    1. Supply two sides. Import a JSON manifest or select files. File selection creates a fresh, partial inventory and replaces that side’s manifest in this session.
    2. Compare the evidence. The Rust engine hashes selected bytes with SHA-256. Imported hashes remain reported claims. A path hash never verifies file content.
    3. Review exceptions. Inspect missing files, changed bytes, duplicate candidates, supplied metadata and relationships. Notes and acknowledgements stay in memory.
    4. Keep an audit. Export JSON includes evidence, unknowns, and human review. It contains file names and your notes, so share it carefully.
    2,000 records and 4 MiB per manifest. Local files: 100 per side, 32 MiB per file, 256 MiB total per side. No metadata extraction, live cloud connection, or deletion recommendations.
    Refreshing clears this session. Downloads are the only way to keep your review.
